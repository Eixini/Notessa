# 2.0.0 (26.03.2024)
## Features
- Added creation and viewing of a new type of note - Todo note
- Removed application frame
- Added styles to the application
- Added Russian language support
- Added settings where you can change the style and language
(after changing the language you need to manually restart the application)
- The ability to open images has been removed from PaintNote

# 1.3.0 (18.03.2024)
## Features
- Added checking media devices and the ability to select a microphone and camera in a video note.
- Removed the ability to pause video note recording.

# 1.2.1 (17.03.2024)
## Bug Fixes
Fixed a problem with the communication application crashing when selecting a microphone 
and quickly opening and closing the voice and video note creation windows again.

# 1.2.0 (16.03.2024)
## Features
Added the ability to select a microphone in the voice memo creation window.

# 1.1.0 (15.03.2024)
## Features
- Added the ability to set the color and size of the brush in the paint note
- before creating a paint note, you need to set the canvas size
- The following supported image formats have been added to the paint note when selecting a file to open:
*.jpg *.bmp *.pbm *.xbm *.xpm *.ppm (including existing ones *.png *.jpeg)
